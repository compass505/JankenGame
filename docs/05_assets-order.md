# 画像発注書（そのまま作業指示に使う）

> **これは作業用。** 判断の理由・不要と判断したものは `docs/05_assets.md` にある。
> ここには**作るものだけ**を書く。

## 共通ルール

- 保存先は `public/assets/`。**ファイル名は下の指定どおり。1文字も変えない**
  （コード側がこの名前を直接参照するため）
- 形式は **PNG**
- 敵と手は**背景を完全に透過**させる。背景画像だけ不透過
- 各プロンプトは**先頭3行の共通句を含んだ完結した文**。そのまま1枚ずつ渡せる
- 共通句は**8枚すべてで同じ文言のまま**にする。ここを変えると画風が揃わない

## 生成が終わったら

```bash
ls -la public/assets/
```

8枚（＋任意で背景）が指定どおりの名前で並んでいれば完了。
**リサイズや切り抜きは不要。** 表示サイズへの縮小は CSS 側でやる。

うまくいかなかった枚だけ、そのプロンプトを再実行すればよい（各プロンプトは独立している）。
