## アートディレクション（全画像共通）

**キャラ（敵5体・手3種）は丸く明るいポップな造形・背景透過。
舞台（戦闘背景）は暗く、対決の緊張感を出す。** 両者は明るさで意図的に対比させる
（グリコが子どもの遊びであることに由来する親しみやすさ vs 戦いの緊張感）。

この対比があっても**線の太さ・塗りの単純さ・輪郭の描き方といったレンダリングの流儀**は
統一しないと、並べたときにバラバラに見える。そのため、明るさとは独立した
**共通句を全9枚のプロンプトの先頭に必ず同じ文言で入れる**。

```
フラットなベクターイラスト風、太く均一な輪郭線、少ない色数でまとめた配色、
丸みを帯びたシンプルな形でまとめる、細かいグラデーションや書き込みを避ける、
文字・ロゴ・透かしは一切含めない。
```

これに続けて、キャラ系は「丸く明るいポップな配色」を、背景は「暗く落ち着いた配色」を
指定として追加する（各プロンプト本文に個別記載）。

**背景色の基準**: `src/ui/styles/main.css` の `--bg: #14161a`。
背景画像はこの色を基調にする。

**「にらみ」の数字を邪魔しない**という制約は背景画像1枚に強く効く。
背景は中央〜上部を空白・低コントラストに保ち、模様や光源をそこに置かない
（にらみの数字は CSS 側の光る演出で主役にするため。節「不要と判断したもの」参照）。

> **まず CSS で組み、敵と手が入った画面を見てから「絵にする価値があるか」を判断する**のが安い。

## 敵5体

`docs/03_detailed-design.md` 節6の偏り・耐性・あいこルールが**見た目からある程度想像できる**ことを狙う。
5体とも「丸く明るいポップ」で統一しつつ、色と持ち物で個性を出す。

### `enemy-scarecrow.png`（かかし・1体目）

**意図**: くせがない最初の敵。弱そうで親しみやすい。特別な得物を持たせず、
グリコの「はじめの一歩」感を出す。5体の中で一番シンプルな造形にする。

**プロンプト**（そのまま貼り付け可）:
```
フラットなベクターイラスト風、太く均一な輪郭線、少ない色数でまとめた配色、
丸みを帯びたシンプルな形でまとめる、細かいグラデーションや書き込みを避ける、
文字・ロゴ・透かしは一切含めない。
丸く明るいポップな配色のキャラクターデザイン。麦わらでできたかかしのキャラクター、
継ぎ接ぎの布の服、丸いボタンのような目、控えめな笑顔、特別な武器や持ち物は持たない、
左右対称でくせのない素朴なシルエット、正面を向いて立っている全身、
背景は完全な透過。
```

## 背景1枚

### `battle-bg.png`

**用途**: 戦闘画面コンテナの背景。5戦闘すべてで共通利用（敵ごとに分けない）。

**意図**: 舞台の暗さで対決の緊張感を作る役割。ただし**主役はにらみの数字と敵HP/自HPであり、
背景ではない**。中央〜上部（敵の立ち絵とにらみ表示が乗る領域）は模様や明るい光源を置かず、
低コントラストのまま空けておく。柄は画面の下端・左右の縁に寄せ、対決の場であることが
分かる程度の最小限の情報量にする。

**プロンプト**:
```
フラットなベクターイラスト風、太く均一な輪郭線、少ない色数でまとめた配色、
丸みを帯びたシンプルな形でまとめる、細かいグラデーションや書き込みを避ける、
文字・ロゴ・透かしは一切含めない。
暗く落ち着いた配色の対決の舞台の背景イラスト、ほぼ黒に近い暗いグレー（#14161aに近い色）を
基調にした単色に近いグラデーション、中央から上部にかけては模様や光を置かずのっぺりと暗いまま
にする、画面下端に薄暗い対決の土俵や地面の輪郭だけを控えめに描く、左右の縁にわずかな
輪郭線の装飾を置く程度に留める、キャラクターや文字は描き込まない、画面全体を覆う横長の
1枚絵、背景込みで不透過。
```

## 不要と判断したもの

CSS の図形・テキスト・既存アセットの使い回しで足りるもの。ここを厚くするほど3日に収まる。

| 項目 | 理由・代替 |
| --- | --- |
| **にらみの表示** | 画像にしない。**大きな数字テキスト＋CSSの色/サイズ変化・光る演出（`box-shadow`や`text-shadow`）**で表現する。動的な値（0/1/2）を画像で持つ意味がなく、「増えた瞬間が分かる」動きもCSSの方が軽く作れる。むしろ背景画像側がこれを邪魔しないよう空けておく設計にした |
| **HPバー** | 画像化しない。`div` の幅を割合で変えるだけの単色バーで足りる。敵ごとに色を変える必要もない（要件にない） |
| **じゃんけんボタンの枠・背景** | ボタン自体はCSSの角丸長方形＋色。中に `hand-*.png` を1枚乗せるだけで足りる。ボタン専用の画像は作らない |
| **強化選択画面のアイコン** | 新規に作らない。既存の `hand-rock.png` / `hand-scissors.png` / `hand-paper.png` を使い回す（3択がグー/チョキ/パーそのものなので、そのまま流用できる） |
| **タイトルロゴ** | 画像にしない。CSSの大きな見出しテキスト（フォントサイズ・太字・色）で十分。凝った字体を作るコストに見合わない |
| **結果画面の演出（クリア/ゲームオーバー）** | 専用の演出画像は作らない。テキストと背景色の切り替え（クリアは明るめ、ゲームオーバーは暗め、程度）で足りる。要件にも「アニメーションを作り込まない」とある |
| **敵のヒント表示（偏りの説明文）** | アイコンや図解にしない。`hint` はテキスト1行としてそのまま表示する（`docs/03_detailed-design.md` 節6にすでに文言が確定している） |
| **タイトル/強化選択/結果画面の背景** | 専用画像を作らない。`--bg` の単色（CSS）で統一する。「舞台の緊張感」が要るのは戦闘画面だけと判断し、`battle-bg.png` 1枚に絞った |
| **勝敗の判定表示（勝ち/負け/あいこの演出）** | 画像や派手な演出は作らない。テキスト（「あなたの勝ち」等）と数値の増減で足りる |
| **敵ごとの専用背景・エフェクト** | 敵5体で背景を分けない（要件どおり「敵ごとに分けない」）。個性は敵の立ち絵とヒント文で出す |
| **画面遷移アニメーション** | 作らない。要件で明示的にアニメーション作り込み対象外 |
