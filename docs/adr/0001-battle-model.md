# ADR 0001: じゃんけんを戦闘にどう組み込むか

- ステータス: **未決定**
- 決定日: —

## 背景

じゃんけんを戦闘の中核に据えたRPGを作る。組み込み方によって `domain/` の構造と、
RPG としての伸びしろが決まるため、実装前に1案へ確定させる必要がある。

調査（`docs/00_research.md`）を経て、**グリコ（じゃんけん階段）の「勝ち方によって
得られるものが違う」という非対称を戦闘に持ち込む**方向が有力になった。
戦闘中の行動要素はじゃんけん1回だけに絞る案。詳細は `docs/00_research.md` 節8。

**まだ決定ではない。** `/spec` で確定させる。

## 候補

<!-- /research の結果を要約して並べる。決定は /spec で行う -->

- **形A: 量の非対称** — 手ごとにダメージ量だけが違う（グリコの直訳、3/6/6 等）
- **形B: 種類の非対称** — 手ごとに得られるものの種類が違う（小ダメージ／大ダメージ／回復）
- 参考: 戦闘へのその他の組み込み方は `docs/00b_research-battle.md`（旧調査）に5案
