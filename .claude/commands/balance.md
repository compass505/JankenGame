ゲームバランスを調整する。

## 触ってよい範囲

`src/data/` の中だけ。ロジック（`domain/` `application/`）には手を入れない。

計算式そのものを変える必要があると判断した場合は、勝手に変えずに理由を説明して私の判断を仰ぐ。

## 手順

1. **何が問題かを自分で言語化する**（強すぎる / 弱すぎる / 単調）。
   ここは判断なので自分でやる。
2. 数値の書き換えは Codex に渡してよい。機械的な作業なので安いモデルで足りる。

   ```bash
   git add -A && git commit -m "wip: バランス調整前"
   codex exec --model gpt-5.6-luna --full-auto "src/data/enemies.ts の <敵名> の <項目> を <値> に変更する。src/data 以外は変更しない。" < /dev/null
   ```

3. `npm run check` を通し、開発サーバで**実際にプレイして確認する**。
   ここも判断なので自分でやる。数値が通ったことと面白くなったことは別。
4. 変更した数値と、変更前後で何が変わったかを報告する。
